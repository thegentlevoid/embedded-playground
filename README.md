# Embedded Playground

A personal learning repository for exploring **embedded systems**, from the fundamentals of C programming to bare-metal development, microcontrollers, and real-time operating systems.

This repository documents my journey through embedded development by collecting:

* Code experiments
* Practice exercises
* Notes and explanations
* Small projects
* Useful references and resources

The goal is not just to write code, but to understand how embedded systems work from the ground up.
